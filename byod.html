Bring Your Own Device

NKU and NKCyber are not responsible for damaged, lost, or stolen personal devices.

Devices will be provided but we welcome students to bring their own hardware, if desired.
It may take some extra time to set up, but then you'll have cybersecurity tools ready to go for the future.
If you want to bring your own device make sure it has the following software:
  • A Kali Virtual Machine (Setup Guide for Kali VM)
    • Ghidra
    • Wireshark
    • HashCat
    • NetCat (should come with Kali)
    • VSCode (or text editor of choice)
    • A web browser of your preference
    • Python 3 (should come with Kali)
      • Python 3 pip
      • Python 3 pillow 11.1.0
      • Python 3 pwntools 4.14.0
      • Python 3 pycryptodome 3.21.0
Note: Outside of a virtual environment, the Python dependencies may need to be installed via apt and not pip.
That is, sudo apt install python3-pwntools, instead of pip3 install pwntools.
